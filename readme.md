Consiste em logica de forcar digitar o numero certo de um codigo de barras. O
mesmo com a senha do operador. Cada botao tem uma acao que forca o usuario ir a
um caminho somente.

---

Opcao de usuario ter cadastro no sistema apara recever descontos opcao do
usuario fazer um cadastro rapido para receber descontos Opcao do usuario apenas
prosseguir sem cadastro

---

Botao de ajuda no terminal para chamar operador

---

O usuario nao consegue prosseguir na compra se o carrinho estiver vazio.

Todos os itens do carrinho ficam armazenados na sessao. Assim sempre tera os
itens salvos para a compra, o carrinho so pode ser deletado com senha do
supervisor ao final da compra

.....Estacionamento ..... O estacionamento simula um registro de entrada em um
estacionamento com cancela. Aplicando a hora da entrada. Na saida o ticket deve
ser validado junto a compra para fazer a liberacao e a taxacao do mesmo. Caso o
usuario esqueca de pagar, tera que fazer outra compra no terminal do sistema, ou
chamar um supervisor para fazer a liberacao do pagamento sem ter que fazer uma
compra.

..........SENHA OPERADOR............ senha do operador limpa toda a sessao.
